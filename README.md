# Smart ATM Banking Engine (Java)

A Core Java console-based banking software that demonstrates Object-Oriented Programming (OOPs), Exception Handling, and File I/O operations.

## Key Features
- Account Management: Create accounts, Deposit, and Withdraw funds.
- Custom Exception: Custom InsufficientBalanceException to prevent overdrafts.
- Transaction History: Real-time passbook tracking with timestamps.
- File Export: Passbook download feature into a .txt file using Java File I/O.

## Tech Stack
- Java (JDK 8 or higher)
- Collections Framework (HashMap, ArrayList)
- File Handling (BufferedWriter, FileWriter)
